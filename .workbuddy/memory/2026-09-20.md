## 抽屉「拖选文字到外面松手就关闭」的问题

用户反馈：Bot 信息/设置抽屉里按下选中文字、拖到抽屉外再松手，抽屉会关闭，正在填的配置要重填。

- 根因：`click` 事件打在按下点与松开点的最近公共祖先上。按下在抽屉内、松开在遮罩上时，浏览器报的 click target 就是遮罩，旧代码 `e.target === e.currentTarget` 判定为「点在外面」→ 关闭。
- 修法（工作区里已有未提交改动，本次又加固）：`apps/messenger/src/lib/click-outside.ts` 的 `backdropClick()`，遮罩记住按下位置，只有按下也在遮罩上才算「点在外面」。
- 本次加固：10 处 `onmousedown={x.press}` 改成 `onmousedowncapture=`，抽屉内任何元素拦掉 mousedown 都不会让判断失效；新增 CreateGroupSheet 回归测试覆盖该情形。
- 验证：`bun test --conditions browser src/lib tests/uno-utilities.test.ts` 682 全过；`bun run typecheck` 0 error。注意 bun 在 /opt/homebrew/bin/bun，且必须带 `--conditions browser`，否则 Svelte 走 server 构建、mount 报错。
