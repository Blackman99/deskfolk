日程图通过侧栏日历按钮进入，地址为 `?o=routines`，独立占据主页面。桌面端点击任意会话（含打开日程前的同一会话）切回聊天；移动端页头提供纯箭头返回按钮，回到进入日程前的会话或列表。刷新、浏览器前进和后退均恢复对应页面。手机页头的日期翻页与视图切换分行显示，Bot 筛选可展开、收起及重置；事件详情居中弹出，长指令在弹窗内滚动。

信使不展示 token / 花费统计：会话顶栏、侧栏底部及未选会话时的全局统计、会话设置中的统计卡均已移除。后台用量记录与 `/v1/spend` 接口保持不变。

聊天输入区上方输入、下方操作：附件在左，右侧仅保留一个固定大小的圆形按钮。你↔Bot 私聊空闲时为发送箭头，有进行中的轮次（含待批准、待回复）时为停止方块，Stop 只打眼前这轮。群聊不论是否有进行中的轮都保持发送，不出现 Stop；要停就发消息让 Bot 们停下来。私聊生成时允许编辑草稿和添加附件，但按钮、Enter、⌘+Enter 与 Ctrl+Enter 都不会提交；结束或停止后恢复发送并保留草稿。群聊有活轮或判断进行中时仍可发送。输入法选词时 Enter 只确认候选，不发送；上屏后浏览器多打的那一下 Enter 也会吞掉。Shift+Enter 换行不变。消息提交期间禁用发送，空内容、未选会话和只读状态同样不可发。快捷键说明移到输入框外，移动端隐藏说明并使用 44px 操作按钮。多行输入保留末尾空行光标，占位提示只在草稿为空时显示。收到停止 / 改道 / 中断事件时，对应待批准卡同步作废，主转录按钮与侧栏状态即时一致。中断行和其他 Bot 消息一样带头像与名字，「继续」贴在「中断」气泡后面，点了新开一轮。

开发态同源 `GET /__local-api` 读守护进程的 `local-api.json`，返回 `{ name, port, token }`。页面 JS 不读 Application Support，只用 `port` 和 `token`，origin 按当前页是 `127.0.0.1` 还是 `[::1]` 拼（Vite 常只听 IPv6 回环）。Tauri 窗走 `local_api_endpoint` command，token 只放内存。托管生产包 `pnpm --filter @real-bot/messenger build:hosted`（`REAL_BOT_HOSTED=1`）不编译该发现路径和本机 bearer；未配对时显示扫码界面，已配对但主机不可达时显示「执行主机不可达」，不排队离线命令。公网配对默认关闭；S-rev / G-uv / 真机 L1 未过。可选待办推送需直接手势；`notificationclick` 只打开 PWA 并拉收件箱，绝不批准。浏览器冒烟不是 iOS 主屏幕 / G-push。
