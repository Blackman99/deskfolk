桌面侧栏底部是带文字的三个入口：工作区（仍是 ⌘O）、工具、设置。工具菜单依次是日程、花费、新建终端；分隔线后是已归档会话，数量只在菜单里以灰色显示，工具按钮保持简洁。新建终端新开一条 shell；已经开着、没被标签摆出来的，仍从窗格「＋」或空窗格接回。日程和花费再打开时定位到已有标签，不另开一块。设置保留更新小红点。外观在 设置 → 基础偏好 → 外观。手机仍用搜索旁的工具菜单（仍叫终端，打开终端页），底部导航（会话 / 工作区 / 设置）保留。手机终端页的地址是 `?o=terminal`，刷新、前进和后退都回到这一页；返回回到打开它之前的会话或列表，shell 继续由守护进程持有。

日程图从桌面「工具 → 日程」进入（手机工具菜单里仍叫日程图），地址为 `?o=routines`，独立占据主页面。桌面端点击任意会话（含打开日程前的同一会话）切回聊天；移动端页头提供纯箭头返回按钮，回到进入日程前的会话或列表。刷新、浏览器前进和后退均恢复对应页面。手机页头的日期翻页与视图切换分行显示。名册筛选在手机和桌面都是收起的可搜索下拉，只列有日程的 Bot，可重置；事件详情居中弹出，长指令在弹窗内滚动。

花费从桌面「工具」菜单第二项、手机搜索旁的工具菜单和桌面「视图」菜单打开：宽屏是唯一的 `spend` 窗格标签，窄屏是 `?o=spend` 浮层。概览和调用明细共用常驻顶栏；`SpendView` 按容器宽度排版，≤620px 的桌面分屏、浮动小窗和手机将表格转为纵向记录与原生排序选择，趋势最多 28 个区间且可点选/键盘查看。时间范围和维度保存在本机；总计、类别、按日趋势、可排序维度表及分页明细共用筛选，可叠加模型 / 会话 / Bot。实报和估算分别合计，缺值显示「—」，已删除对象显示名称快照。会话顶栏、会话列表行、会话设置及流程图继续保持原有展示。信使通过 `/v1/spend/summary` 读取守护进程聚合结果，`/v1/spend` 读取分页明细；`spend.created` 触发去抖刷新，快照和客户端状态不累计账本。

聊天输入区上方输入、下方操作：附件在左，右侧仅保留一个固定大小的圆形按钮。你↔Bot 私聊空闲时为发送箭头，有进行中的轮次（含待批准、待回复）时为停止方块，Stop 只打眼前这轮。群聊不论是否有进行中的轮都保持发送，不出现 Stop；要停就发消息让 Bot 们停下来。私聊生成时允许编辑草稿和添加附件，但按钮、Enter、⌘+Enter 与 Ctrl+Enter 都不会提交；结束或停止后恢复发送并保留草稿。群聊有活轮或判断进行中时仍可发送。输入法选词时 Enter 只确认候选，不发送；上屏后浏览器多打的那一下 Enter 也会吞掉。Shift+Enter 换行不变。消息提交期间禁用发送，空内容、未选会话和只读状态同样不可发。快捷键说明移到输入框外，移动端隐藏说明并使用 44px 操作按钮。多行输入保留末尾空行光标，占位提示只在草稿为空时显示。收到停止 / 改道 / 中断事件时，对应待批准卡同步作废，主转录按钮与侧栏状态即时一致。中断行和其他 Bot 消息一样带头像与名字，「继续」贴在「中断」气泡后面，点了新开一轮。Bot 私聊里同样能点：一轮中断，或「这一轮没写完」（连不上、被拒、运行时出错、卡住），都有「继续」，不因为那边没有输入框就收起。
