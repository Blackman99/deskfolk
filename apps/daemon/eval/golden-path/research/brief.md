# Brief：我们的 Mac 小工具该走哪条分发渠道

我们是三个人的小工作室，正在做一款给开发者用的 macOS 菜单栏小工具（本机运行，要调用 `git` 和 shell；买断还是订阅还没定）。想在上架前定下分发渠道。

请根据工作区 `sources/` 里的资料写一份调研报告。

要求：

- 终稿写到工作区根目录 `report.md`（和本文件并列），不要只贴在聊天里。
- 800–1500 字，中文。
- 结构：背景与问题、三条渠道对比、推荐方案、风险与待核实事项。
- 「三条渠道对比」用一张 Markdown 表格，三条渠道（Mac App Store、官网直接分发、Setapp）都在表里，至少比较：抽成或费用、审核与上架周期、沙盒等技术限制、更新方式、获客。
- 推荐方案要给出明确结论（选哪条，或怎么组合、先后顺序），并说明为什么适合我们这种三人工作室。
- 每个关键事实后面用括号注明出处文件名，例如（sources/setapp.md）。
- 只根据 `sources/` 里的资料和群里的讨论写，不要上网查；资料里没有的就写进「待核实」，不要编。
- 过程笔记可以另存，不要改动 `sources/` 里的文件。

不要指定谁做哪一步。
