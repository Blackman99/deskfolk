# 官网直接分发（整理笔记）

整理于 2026 年 8 月，摘自苹果「在 Mac App Store 以外分发」文档和两家支付平台的定价页。

- 签名与公证：同样需要开发者计划（99 美元 / 年），用 Developer ID 证书签名，并提交苹果公证（notarization）。不公证的应用第一次打开会被 Gatekeeper 拦下，用户要去「系统设置 → 隐私与安全性」手动放行，转化明显下降。
- 公证一般几分钟到一小时出结果，是自动检查，不是人工审核，不看功能。
- 沙盒：不强制。可以调用命令行工具；读写文件仍受系统隐私权限约束（例如完全磁盘访问要用户自己打开）。
- 收款：常用 Paddle、Lemon Squeezy 这类「记录商户」（Merchant of Record）平台，代收代缴各国增值税，费用大约每笔 5% + 0.5 美元；也可以直接接 Stripe（约 2.9% + 0.3 美元，但税要自己处理）。
- 许可证：要自己做许可证密钥和激活，或者用支付平台自带的许可证功能。
- 更新：一般集成 Sparkle 自动更新框架，发版节奏完全自己定。
- 获客：全靠自己的官网、社区、内容和口碑，没有商店自带的流量。
