# Brief：Tidemark 上线物料

`product.md` 是我们要上线的产品。下周在 Product Hunt 和自己的网站同时发布，需要两样东西：

1. `launch/copy.md`：上线文案，包含
   - 3 个备选主标题（每个不超过 20 个字）和 1 句副标题；
   - 3 段功能介绍，每段对应 `product.md` 里的一项核心功能；
   - 一段 Product Hunt 介绍（150–250 字）；
   - 3 条可以直接发的社交媒体短帖（每条不超过 140 字）；
   - 3 条常见问答，其中一条必须回答「支不支持云同步」。
2. `launch/index.html`：单文件落地页
   - 所有 CSS 写在这个文件里，不引用任何外部脚本、样式表、字体或图片（可以用内联 SVG 或纯 CSS）；
   - 有主标题、功能区、价格区、常见问答和一个下载按钮，按钮链接到 `product.md` 里的下载地址；
   - 价格和系统要求与 `product.md` 一致；
   - 手机宽度（375px）下能正常阅读：有 viewport meta，不出现横向滚动。

口径：只写 `product.md` 里有的功能和数字，不要编造用户数、评分或媒体报道。文案和页面里的主标题、价格要一致。

不要指定谁做哪一步。
