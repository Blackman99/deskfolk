# Tidemark

一句话：给按小时计费的独立开发者和设计师用的本机工时记录工具。

## 平台与价格

- macOS 13 Ventura 及以上，Apple 芯片和 Intel 都支持。
- 个人版 29 美元一次性买断，含一年免费更新；一年后不续费也能一直用当时的版本。
- 14 天免费试用，不用填信用卡。
- 下载地址：https://tidemark.example.com/download

## 核心功能

1. 按项目计时：菜单栏一键开始 / 暂停，也可以在终端里用 `tidemark start <项目>`、`tidemark stop`。
2. 自动关联 Git 提交：计时期间在项目仓库里的提交会自动挂到这段工时上，月底对账时能看到每段时间做了什么。
3. 导出账单草稿：按客户和月份导出 CSV，或生成一份 Markdown 账单草稿（含工时明细和按小时费率算出的合计）。

## 明确不做

- 不做云同步：数据只存在本机（`~/Library/Application Support/Tidemark`），可以用任意备份工具自己备份。
- 不做团队版和多人协作。
