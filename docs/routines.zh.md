# 每日与每周日程

[English](routines.md)

Bot 可以按设定的时间自己开工：每天，或每周选定的几天。这一页讲日程在哪里看、怎么改，以及它按什么规则执行。

回看不是日程。它是 Bot 在一条会话里给自己约的一次性叫醒（`check_back` 工具），一分钟到七天后，用来回头核对交出去或正在等的活。只响一次，落在同一会话、同一件事里，叫醒它的那一行只有它自己读得到（会话里不显示），不进日程图；约它的那一轮被 Stop、会话清空或删除、Bot 删除都会作废。应用也会替 Bot 约一次：它开的 Bot↔Bot 私聊静下来约 10 秒后，就在开这条私聊的那个会话立刻叫醒它，交代私聊的结果；私聊里没有新的话就不再叫，从这种回看开出去、对方一句没回的私聊也不再叫回。

桌面上，侧栏底部的**工具**再点**日程**打开**日程图**（桌面「视图」菜单里也还有；已经开着的日程图会定位到已有标签）。手机上仍在搜索旁边的工具菜单里，仍叫**日程图**，打开日程图那一页：有日程的 Bot，其每天和每周日程铺在同一张周视图里，只读。没有日程的 Bot 不出现。名册筛选是一枚可搜索的下拉，按名字或职责找，点一行隐藏或显示这个 Bot 的格子。议程里每一行也标出这个 Bot 的头像和名字。格子是规则展开，不是每次运行的记录；钟点按执行 Mac 的本地时间标出。改时间仍在 Bot 资料里做，手机上不能拖。

打开 Bot 资料（Bot 头像/名字 → 资料），在 **日程 → 新建日程** 中填写标题、任务指令，选择**每天**或**每周**（至少一天），再选时间。日程归当前 Bot。宽屏上，日程条数在「日程」标签上，日程直接列在页面里：每行右边是启停开关和删除按钮，点一行，编辑表单就展开在它下面；列表末尾的「新建日程」在同一处打开新建表单。手机上，日程条数和「新建日程」在日程页的顶栏里；点一条日程会打开整页，进入时不自动聚焦输入框：时间用系统时间选择，星期是一排可点的日子，启用是开关；暂停和删除不跟列表挤在一行里，删除在这一页底部，返回先回到日程列表。侧栏搜索日程会打开所属 Bot 的资料和对应编辑页。后来的搜索或关闭操作会取消较早的待完成跳转；所属 Bot 已删除的历史日程仍保留，但在搜索中标为不可用。确认框限制键盘焦点，取消后归还触发控件，保存中不能关闭。

时间按**执行 Mac 的本地时区**解释，不按浏览器时区换算；没有单条日程时区或 cron 表达式。Mac 需醒着且运行时可用；恢复后只补最近一次，不逐次补跑；从睡眠醒来后先等一分钟左右再补，合盖时系统自己醒几秒不算醒着；归档 Bot 不执行日程。删除或暂停不会停止已经开始的任务。列表通过事件跨客户端实时更新，重连后刷新；另一客户端修改了正在编辑的日程时，先载入最新版本再保存，旧版本保存和删除会被拒绝，不会静默覆盖。连接中断不会自动重试写入，请重连后核对列表。请求结果未知时，可在日程页点击**重试原请求**，仅重发原内容和请求编号，不发送后来修改的草稿；待确认载荷提示不是版本冲突。原请求结束待确认后，修改的草稿仍保留显示，但需先核对列表并重新打开日程，才能继续提交。
