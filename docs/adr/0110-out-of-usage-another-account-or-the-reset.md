# 额度用完：换你的另一个账号接着做，都用完就到点自己接着做 / Out of usage: another of your accounts goes on, or the work picks up at the reset

Status: implemented 2026-11-12. Amends [ADR 0061](0061-claude-agent-runner.md) (its accounts addendum left "auto" until you asked) and [ADR 0109](0109-the-app-says-less-when-work-stops.md) (its first trade-off: nothing resumed by itself after the reset).

你试用时常撞上 Claude 的 5 小时或每周额度：10 月 14 日到 11 月 5 日，私聊里有二十多条「这一轮没写完：Claude 的用量额度用完了（… 重置）」，10/23 那三条要等到 10/27。这台 Mac 上登录着两个 Claude 账号（`~/.claude` 和 `~/.claude-b`），两个 Bot 各用一个；一个用完时另一个往往还有，但 Bot 只认自己那个账号，要你手动在 Bot 面板里换、再按「继续」，或等到重置时间再按。ADR 0061 当时把「自动挑剩得多的账号」留到你开口：它会在你没选时挪动花费。你说：要支持自动切换到别的本地已配置订阅，没有可用的也要到期自动继续。

You kept hitting Claude's five-hour and weekly limits while trying the app: from 10-14 to 11-05 the directs got over twenty 「这一轮没写完：Claude 的用量额度用完了（… 重置）」 lines, the three on 10-23 waiting until 10-27. This Mac has two Claude accounts signed in (`~/.claude` and `~/.claude-b`), one Bot on each; when one ran out the other often had room, but a Bot knew only its own, so you switched it by hand in the Bot panel and pressed Continue, or waited for the reset and pressed it then. ADR 0061 had left "pick the account with more left" until you asked, since it moves spending without you choosing. You asked: switch to another locally configured subscription automatically, and with none left, carry on by itself when the limit resets.

## 决定 / Decisions

1. **「另一个订阅」是同一个 Agent 的另一个账号 / "Another subscription" is another account of the same agent.** Claude 的账号就是设置里列的配置目录，加上守护进程自己环境里的那个（ADR 0061）。读同一个目录的两个写法、或者登录的是同一个邮箱的两个目录，算一个账号：换过去额度还是同一份。只换到用 Claude 套餐登录的账号（claude.ai 登录或它的长期令牌）：用 API key、apiKeyHelper 或第三方平台的账号按 token 计费，换过去就是把套餐的额度上限变成账单，不换（Bot 自己指定的照旧用）。换到别的 Agent（Claude 用完转 Codex）不算：那是另一个 Agent、另一套工具，不做。列出第二个账号，就是同意额度用完时花它。
   An account is a config directory you listed in Settings, plus the daemon's own environment's (ADR 0061). Two handles reading one directory, or two directories signed in as the same email, are one account: moving between them hits the same limit. Only an account signed in on a Claude plan (a claude.ai sign-in or its long-lived token) is moved to: one on an API key, a key helper or a cloud platform is billed per token, and moving there would turn the plan's limit into a bill (a Bot that names one still runs on it). Moving to another agent (Codex once Claude is out) is not this; it is another agent with other tools, and is not done. Listing a second account is agreeing to spend it once the first is out.

2. **记住哪个账号用完到几点 / The app remembers which account is out until when.** 一次请求被套餐额度挡下（Claude Code 的 `rate_limit_event` 为 `rejected`，且没有额外用量接着跑），这个账号记为用完，到它报的重置时间为止；没报时间的（`billing_error`、`account_on_hold`）先当一小时，到时再试，但不按它排任何事。记在 `settings` 的 `agent_accounts_out` 里，守护进程重启也在；这个账号上有一次请求走通了就划掉。
   A request the plan's limit turns away (`rate_limit_event` `rejected`, with no extra usage carrying on) notes the account out until the reset Claude Code reports; one with no reset (`billing_error`, `account_on_hold`) is held out for an hour and tried again, and nothing is scheduled on it. Kept in `settings` (`agent_accounts_out`), so a restart keeps it; a request that goes through on the account clears the note.

3. **一轮开跑前挑账号 / Each turn picks its account first.** Bot（或它爬到的阶梯档）指定的账号没被记为用完，就用它；记着用完，就用列表里第一个登录着、没用完的别的账号，一开始就跑在那边，不先失败一次。都用完了，照旧在指定的账号上跑（可能已经提前恢复了）。Bot 自己的设置不改：额度回来后它回到自己的账号。内置调用（读句、整理器等跑在 Claude 上的）也这样挑，被额度挡下时同样记下；它们本来就会退回词表，不会卡住。
   The account a Bot (or the ladder rung it climbed to) names is used while it is not noted out; while it is, the turn runs on the first other listed account that is signed in and not out, from the start, without failing once first. With every account out, it runs on the one named anyway, which may be back early. The Bot's own setting is not changed, so it returns to its account once the limit is over. Built-in calls on Claude (reading, the organizer, …) pick the same way and note a limit they meet; they already fall back to the word lists and never stall.

4. **一轮中途用完，在同一轮里换账号接着做 / Out mid-turn, the same turn goes on on the next account.** Claude Code 把会话存在它跑的那个账号下面，换了账号就是新会话；新会话开头是这一轮原本的输入，再加一段应用提示：原先的账号额度用完了、换了账号，上一个会话这一轮已经做了哪些（调用、结果、说过的话，取最近的约 6000 字），文件和命令结果都还在，不要重做，从断掉的地方接着做。会话里不出任何行、不发通知；轮次不结束、不记失败，监督器也不把它当成停下的 Bot。工作记录里记一条 `agent.account_switched`（从哪个目录到哪个，和重置时间）。每个账号一轮最多试一次。
   Claude Code keeps a session under the account it runs on, so another account is a new session. It starts with the turn's own input plus an app note: the account ran out, the turn goes on on another one, and what the session before did in this turn (calls, results, what it said; the latest ~6,000 characters), with the files and results still there, not to be redone. Nothing shows in the conversation and no notification goes out; the turn neither ends nor records a failure, so the supervisor does not see an agent out. The work log gets `agent.account_switched` (from which directory to which, and the reset). Each account is tried at most once per turn.
   没有走「失败一次再按继续」：那样会从一行藏起来的失败行接着做（没人走过的路），还会记一次失败、一条 `turn.failed`，让监督器以为这个 Bot 的 Agent 用完了。 / Not "fail, then Continue": that would continue from a hidden failure line, a path nothing exercises, and record a failure, a `turn.failed` and an agent-out state for something that is not one.

5. **都用完了，到点自己接着做 / With every account out, the work picks up at the reset.** 失败行照旧显示一次，但写明什么时候自动接着做（「这一轮没写完：Claude 的用量额度用完了（11/5 13:10 重置，到时自动接着做）」；最早回来的是另一个账号时写那个时间）。到了那个时间加一分钟，调度器像你按那条的「继续」一样接着做：同一个会话、同一件事；不算你说的话，所以你的叫停照样拦住它。没有要你做的事，所以不发通知。不再接着做的情况：你已经按过「继续」、这件事后来有过一轮不是因为额度结束的（你说了话并且跑通了、你叫停了、它正在干），或者被叫停、Bot 或会话没了。守护进程正在排空时等下一拍；盖子合着的暗唤醒里不跑。只有 Agent 自己报了重置时间才排：Claude Code 的、Codex 的（它的 `account/rateLimits/updated`）；别的本机 Agent 报不出时间，照旧等你。和它重复、被藏起来的失败行（ADR 0109）不另排：被它重复的那一行已经排了。
   The failure line still shows once, saying when it picks up (「…（11/5 13:10 重置，到时自动接着做）」; the other account's time when that one is back sooner). A minute after that time the scheduler continues it as that line's Continue would: same conversation, same job. It is no word of yours, so a stop of yours still holds it. Nothing is asked of you, so no notification. It is let go when you pressed Continue already, when the job had a later turn that did not end out of usage (you spoke and it got through, you stopped it, it is at work), or when a stop holds it or the Bot or conversation is gone. While the daemon drains it waits for the next tick, and it does not start in a dark wake. Only a reset the agent itself reported is scheduled on: Claude Code's and Codex's (`account/rateLimits/updated`); other local agents report none and wait for you as before. A hidden repeat of the line (ADR 0109) schedules nothing of its own: the line it repeats already did.
   记在 `settings` 的 `agent_limit_resumes` 里（失败行、它结束的那一轮、时间），重启也在。 / Kept in `settings` (`agent_limit_resumes`: the line, the turn it ended, the time), so a restart keeps it.

## 取舍 / Trade-offs

- **换账号就是换会话。** 新会话只拿到上一个会话做了什么的摘要，拿不到它的完整上下文；长的一段换过去，前面的细节会少一些。把会话记录拷到另一个账号的目录里能原样接着，但那是往你的 Claude 配置目录里写东西，ADR 0061 说过应用只读不写。 / **Another account is another session**: it gets a summary of what the one before did, not its whole context. Copying the transcript into the other account's directory would carry it whole, but that writes into your Claude config directory, which ADR 0061 keeps read-only.
- **花费会挪到另一个账号上。** 一个账号的 Bot 用完后会花另一个账号的额度，那个账号上的 Bot 也就更早用完。没有按 Bot 关掉的开关；要某个 Bot 只用自己的账号，现在只能不列出别的账号。 / **Spending moves**: a Bot that ran out spends the other account, and that account's own Bots run out sooner. There is no per-Bot switch to turn it off; listing only one account is the way for now.
- **没报重置时间的不等。** 计费错误、账号被暂停这类，应用不知道什么时候好，照旧等你。 / **No reset, no wait**: a billing error or an account on hold says no time, so it waits for you as before.
- **项目会话没做。** 项目会话的会话记录在它的账号目录下，换账号接不上（同上一条的原因）；它撞额度时照旧停下，要你等重置后再说一句。 / **Project sessions are not covered**: their transcript lives under the account's directory, so another account cannot carry it on (as above); they stop on the limit as before.
- **按模型的额度也记整个账号。** 每周额度里有只管 Opus 或 Sonnet 的（`rateLimitType` 为 `seven_day_opus` / `seven_day_sonnet`）；被它挡下时整个账号记为用完，用别的模型的 Bot 和内置调用也会换走，可能好几天，虽然那个账号还能跑它们。 / **A model's own weekly limit notes the whole account**: one turned away by `seven_day_opus` / `seven_day_sonnet` moves Bots and built-in calls on other models off it too, possibly for days, though it still serves them.
- **不挑剩得多的。** 按设置里的顺序取第一个没用完的，不先去问每个账号还剩多少：那要每个账号起一次 `claude`，几秒到几十秒。 / **First, not fullest**: the first account not out, in Settings' order; asking each account how much is left would start `claude` once per account, seconds to tens of seconds.
