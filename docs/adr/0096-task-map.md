# 任务地图：把 Agent 干活的过程画成项目目录的小镇 / Task map: an agent's work drawn as a town of the project's folders

Status: implemented 2026-10-20. Builds on [ADR 0095](0095-project-sessions.md) (project sessions), whose replay route and live tool frames it reads.

2026-10-20 你想把 Bot 执行的过程可视化得更彻底：Bot 当前在处理什么文件，流程做成游戏地图，Bot 是在各个地点之间来回做任务的角色。先在原型上试了：一个 Bot 任务的回放，再改成等距 3D、能平移缩放旋转、每栋楼长得不一样、人物带头像、每一步标出执行它的模型。你问能不能用到项目会话上，原型就拿做项目会话的那个 Claude Code 会话本身跑了一遍，缺的几处在 ADR 0095 那边补上（每次调用的地点和模型、回放接口），这里把地图做进应用。

On 2026-10-20 you wanted a Bot's work shown more fully: which file it is on, the flow as a game map, the Bot a character going between places doing quests. A prototype came first: one Bot job's replay, then an isometric 3D town you can pan, zoom and turn, each building its own shape, the characters with their avatars, every step marked with the model that ran it. Asked whether it fits project sessions, the prototype was run on the very Claude Code session that built them; what was missing went into ADR 0095 (each call's place and model, the replay route), and the map comes into the app here.

## 决定 / Decisions

1. **项目会话的一种窗格 / A pane kind of a project session.** `map` 窗格，一个项目会话一个（和流程一样 `ONE_PER_SESSION`），默认开在右侧窗格。入口是项目会话右键菜单里的「打开任务地图」和它窗格顶栏、标签 ⋯ 里的「地图」；只在宽窗口有工作台时给出，手机和窄窗口以后再做。 / A `map` pane, one per project session (`ONE_PER_SESSION`, as the flow is), opening beside the conversation by default. It opens from Open task map in the project session's context menu and Map in its pane header and its tab's ⋯; only where a workbench holds it — a phone and a narrow window come later.

2. **地点是目录，固定地点另算 / Places are folders, with fixed places besides.** 打开时按回放里每次调用的 `place` 分区：从调用最多的目录往下拆，最多 10 个代码区，每区至少占 3% 的调用或 2 次，太小的并进「仓库别处」；另有项目根（提问、派分身）、测试场（测试和类型检查）、版本库（git）、Claude 会话库（`~/.claude*`）和项目外。区一旦排好就不随实时调用重排：新路径按目录归到已有的区，会话长到原来的一倍半才在两轮之间重排；只有新会话例外，还没有一个代码区时，头几次调用进来就排。楼的形状按目录名挑（docs 是图书馆、store 是档案室……），每种形状一张地图只用一次，颜色也就各不相同。 / The replay's `place` of each call lays the town out when the map opens: split from the busiest folder down, at most ten code districts, each with 3% of the calls or two, the small ones joining 「仓库别处」; besides those, the project's root (questions, subagents), checks (tests and type checks), git, Claude Code's own files (`~/.claude*`) and outside the project. Once laid out the town does not move with live calls: a new path joins the district whose folder holds it, and only a session grown half again is laid out anew, between runs — except a new session, laid out by its first calls as they come in while it has no code district yet. A building's shape follows its folder's name (docs a library, store an archive…), each shape at most once a map, so no two places share a colour.

3. **角色和执行者 / Characters and who ran a step.** Agent 本身是主角，它派出的每个子代理是一个小一号的角色，只在第一步和最后一步之间出现，从主角那里走出去、做完走回来。身体是应用自己的 folk 形象（按名字生成，动作跟着状态）；名牌上是 Agent 的 logo（`AgentLogo`，Claude Code 是 Claude 火花标）和这一步的模型（`claude-opus-5-5` 写成 Opus 5.5）。模型按每次调用自己的 `model` 取，不按子代理的说明取：Explore 子代理的说明里没写模型，实际跑在 Opus 上。 / The agent is the main character and each subagent it sent out a smaller one, on the map only between its first and last step, walking out from the agent and back. Bodies are the app's folk figures (from each name, acting out their status); the badge carries the agent's logo (`AgentLogo`: the Claude Spark for Claude Code) and the step's model (`claude-opus-5-5` as Opus 5.5). The model is each call's own `model`, not the subagent's: an Explore subagent names none and runs on Opus.

4. **回放和实时是同一张图 / Replay and live are one picture.** 打开时读 `GET /v1/project-sessions/:id/replay`，之后的工具帧（带 `agent_run` 的 `ToolFrame`）按调用 id 记在 `AgentCallLog` 里，叠在回放上：一个调用在两边都有时以回放为准。一轮结束和重连之后重新读回放。打开时停在最新一步（会话在跑就跟着最新一步走，标「实时」）；播放从头开始，时间轴照原型压缩（超过 15 分钟的空档各算 4 秒）。 / The map reads `GET /v1/project-sessions/:id/replay` when it opens; the tool frames after that (`ToolFrame` with `agent_run`) are kept by call id in `AgentCallLog` and laid over the replay, the replay winning where both hold a call. A run ending and a reconnect read the replay again. It opens at its newest step (following the newest step, marked Live, while the session runs); playing starts from the beginning, on the prototype's squeezed clock (a gap over 15 minutes takes 4 seconds).

5. **值得看的时刻只描述不评判 / Moments describe, they do not judge.** 派出分身、停下来问你（等了多久）、你又说了一句、长时间没有动静（是不是在等你）、一次调用被拦下（你在卡上、应用的规则、安全检查）、你在卡上允许了一次改动、失败次数、半分钟以上的调用、两地之间来回。`user_temporary` 只有不是 AskUserQuestion 时才算批准：终端会话里 Claude Code 把你回答问题也记成它。 / Sending out a subagent, stopping to ask you (and how long it waited), you saying more, a long pause (and whether it was waiting for you), a call stopped (by you on the card, the app's rules, a safety check), a change you allowed on its card, failures, calls of half a minute or more, back and forth between two places. `user_temporary` is an approval only when the call is not AskUserQuestion: in a terminal session Claude Code records your answers to its questions that way too.

## 取舍 / Trade-offs

- **只有项目会话 / Project sessions only.** Bot 的任务也能这样画（原型就是），但它的 `tool_executions` 没有记目标路径，`write_file` 只有极少数找得回位置；等那边记下目标再接，`MapData` 已经和会话种类无关。 / A Bot's job could be drawn the same way (the prototype was one), but its `tool_executions` keep no target, so few `write_file` calls can be placed; once they do, `MapData` already does not care which kind of session it came from.
- **记录在应用外 / The record lives outside the app.** 回放读的是 Agent 自己的会话文件，文件被删就画不出来，和 ADR 0095 的取舍一样。 / The replay reads the agent's own session files; with them deleted there is nothing to draw, the same trade-off as ADR 0095.
- **画面是一张画 / The picture is a picture.** 小镇的颜色不跟深色主题变，牌子和名牌在两种主题里都是白底；叠在上面的控件和卡片用应用的颜色。 / The town's colours do not follow the dark theme, and its plates and badges are white in both; the controls and cards over it use the app's colours.
- **没有手机页 / No phone page yet.** 手机和窄窗口打不开地图，入口也不给出。 / A phone or a narrow window cannot open the map, and is not offered it.

## 实现 / Implementation

信使 `src/lib/taskmap/`：`map-data.ts`（回放读成 `MapData`、叠上实时调用）、`districts.ts`（分区）、`timeline.ts`（压缩的时钟、时刻、车道）、`live.svelte.ts`（`AgentCallLog`，挂在 `ChatActivity` 上，`runtime.agentCalls`）、`frame.ts`（一帧：谁在哪做什么、每栋楼和牌子）、`inspect.ts`（地点详情）、`moment-text.ts`；画面在 `scene/`（投影、建模、15 种楼、地面、牌子排布、相机，和原型逐项比对过）；组件 `TaskMap`、`MapScene`、`MapHud`、`MapTimeline`、`MapSide`。窗格种类 `map` 在 `workbench/pane-content.ts`，入口在 `Shell.svelte` 的 `chatTabActions` 和 `sidebar/session-context-menu.ts`；`ApiBase.projectReplay`。

The messenger's `src/lib/taskmap/`: `map-data.ts` (the replay read as `MapData`, live calls laid over it), `districts.ts`, `timeline.ts` (the squeezed clock, moments, lanes), `live.svelte.ts` (`AgentCallLog`, on `ChatActivity`, as `runtime.agentCalls`), `frame.ts` (one frame: who is where doing what, every building and plate), `inspect.ts` (a place's card), `moment-text.ts`; the picture in `scene/` (projection, modelling, the fifteen buildings, the ground, plate layout, camera; checked against the prototype case by case); the components `TaskMap`, `MapScene`, `MapHud`, `MapTimeline`, `MapSide`. The `map` pane kind is in `workbench/pane-content.ts`, its entries in `Shell.svelte`'s `chatTabActions` and `sidebar/session-context-menu.ts`; `ApiBase.projectReplay`.
