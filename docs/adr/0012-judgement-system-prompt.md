# 判断提示词是固定中文 system，载荷是纯 JSON user

判断不是轮次：指令与身份不能糊在同一条 user 里，也不能每人插值一份 system（身份已在 [判断只许 join 或 pass，失败当旁观](0004-judgement-join-pass-only.md) 那份 JSON 的 `you`）。system 一个 `{` 都不放，因为主机对 assistant 抽「第一个对象」——合法 JSON 例子会被抄成永远 `join`。任意 OpenAI 兼容端点上 `response_format` 会 400，每次判断变 `pass`，黄金路径 A（开场不点名）全灭，所以不发、靠提示词加抽取。只锁中文指令、英文枚举；职责匹配则倾向 `join`，否则开场不点名的三人不会下场。用户向全员提出的工作请求不是打招呼。禁止为礼貌全员 `join` 或把用户已说过的请求再点名一遍（v1 无熔断）。判断何时跑见 0004：只对用户无点名群消息。
