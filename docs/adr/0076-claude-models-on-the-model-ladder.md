# 阶梯上的 Claude 模型 / Claude models on the model ladder

Status: implemented 2026-10-10, from engine level 7 (the ladder's own level). Extends [ADR 0054](0054-model-ladder-and-in-turn-triggers.md)'s ladder with the Claude models of [ADR 0061](0061-claude-agent-runner.md), the way [ADR 0055](0055-lines-read-by-a-model.md)'s reader model already took them.

你说的是（2026-10-10）：「阶梯模型要支持 agent 设置里的那些。」在这之前，阶梯只能排端点上的模型；Claude Agent 设置里能选的 Claude 模型、思考强度和账号排不上去，而读句模型早就能选它们了。

You put it this way (2026-10-10): the model ladder should take the ones in the agent settings. Until now the ladder held only endpoint models; the Claude models, efforts and accounts that Claude Agent settings offer could not be rungs, though the reader model already took them.

## 决定 / Decisions

1. **一级可以是 Claude 模型 / A rung may be a Claude model.** `ModelLadderRung` 成了 `ModelLadderEndpointRung | ModelLadderClaudeRung`；Claude 级是 `{ runner: "claude_code", model, effort, config_dir }`：模型是别名或完整 id（`isClaudeModelName`），思考强度是 Claude Code 的 `--effort` 档或 null（Claude Code 的默认），账号是设置里列出的配置目录或 null（守护进程环境里的那个），和 Bot 的 `agent_model` / `agent_effort` / `agent_config_dir` 一一对应。两级相同指同一端点同一模型，或同一 Claude 模型、同一思考强度、同一账号（`sameLadderRung`）：opus 高、opus 最大可以各占一级。存法不变，还是 `settings.model_ladder` 一行 JSON；端点改名单或被删只拿掉它自己的级，Claude 级不动。/ `ModelLadderRung` is now `ModelLadderEndpointRung | ModelLadderClaudeRung`; a Claude rung is `{ runner: "claude_code", model, effort, config_dir }` — an alias or full id (`isClaudeModelName`), a Claude Code `--effort` level or null for its default, and one of the accounts listed in Settings or null for the daemon's own — mirroring a Bot's `agent_model` / `agent_effort` / `agent_config_dir`. Two rungs are the same when they name the same endpoint and model, or the same Claude model at the same effort on the same account (`sameLadderRung`): opus high and opus max may each be a rung. Storage is unchanged, one JSON row in `settings.model_ladder`; an endpoint's list changing or the endpoint going takes only its own rungs, never a Claude one.

2. **爬到 Claude 级，下一轮交给 Claude Code / Climbing onto a Claude rung hands the next turn to Claude Code.** 选路（`routing.ts` 的 `climb`）照旧从这一轮本来的端点模型往上数级；数到 Claude 级时返回的 `Routed` 带上 `claude`，记的原因是 `escalation_model`。应用自己的循环在开这一轮时（`openRun`）看到它，就不跑跳，把这一轮交给 `agentRunner.runAgentTurn(turnId, rung)`：模型、思考强度、账号用这一级的，其余（工作区边界、批准、叫停、收尾契约、记录）和 Claude Agent 的 Bot 一模一样。选路记录原因是 `claude_code`，`base_reason_code` 是 `escalation_model`，所以也不算进 Bot 默认模型的推断。中途不换：和端点级一样，爬到的模型等这件活的下一轮。Claude 模型都能看图，要看图的活不跳过它；装没装、登没登录由那一轮自己发现，照 Claude Agent 的失败说一句。/ Routing's `climb` still counts rungs up from the endpoint model the turn would have run on; landing on a Claude rung returns a `Routed` carrying `claude`, reason `escalation_model`. The app's own loop sees it when the turn opens (`openRun`), runs no hops and hands the turn to `agentRunner.runAgentTurn(turnId, rung)`: that rung's model, effort and account, everything else — the workspace boundary, approvals, stops, the closing contract, the records — exactly as for a Claude Agent Bot. The route row's reason is `claude_code` with `base_reason_code` `escalation_model`, so it stays out of the Bot's inferred default. Nothing switches mid-turn: as for an endpoint rung, the climbed model waits for the job's next turn. Claude models see pictures, so picture work does not skip them; whether Claude Code is there and signed in is the turn's to find out, failing with the Claude Agent line.

3. **再往上照爬 / The climb goes on above it.** 交付失败按这件活累计（`work_items.escalation`），不管哪一轮是谁跑的，所以在 Claude 级上接着没过，下一轮照样再往上一级；上一级是端点模型就回到应用自己的循环。一轮之内出错提档（ADR 0054 的 trouble）在 Claude Code 跑的轮里仍不算：那是 Claude Code 自己的事。/ Failed hand-overs count per job (`work_items.escalation`) whoever ran the turn, so failing on a Claude rung climbs again at the next turn; an endpoint rung above takes the job back to the app's own loop. Trouble inside a turn (ADR 0054) still steps nothing up on a turn Claude Code runs: that is Claude Code's to handle.

4. **Claude Agent 的 Bot 不爬 / A Claude Agent Bot does not climb.** 它的 Claude 模型是你钉的；钉的不换是阶梯一直的规矩（只有应用替 Bot 选的模型沿阶梯换）。/ Its Claude model is your pin, and the ladder has always moved only what the app chose.

5. **只有你把 Claude 模型排上去 / Only you put a Claude model on the ladder.** 它花的是你的 Claude 套餐，和读句模型、Bot 的运行方式一样只有你能选。Bot 的 `list_endpoints` 照原样列出 Claude 级；`update_model_settings` 可以原样传回来保留或挪位置，也可以不传而拿掉，传一个阶梯上没有的 Claude 级（换模型、思考强度或账号也算）就拒绝（403）。阶梯上某一级用着的账号，拿掉或换掉那一级之前不能从账号列表里删掉，和 Bot、读句模型用着的账号一样。侧边栏的 Claude 用量也把这些账号算作在用。/ It spends your Claude plan, so as with the reader model and a Bot's runner only you choose it. A Bot's `list_endpoints` shows Claude rungs as they are; `update_model_settings` may pass one back as shown to keep or move it, or leave it out to drop it, and is refused (403) for a Claude rung not already on the ladder — another model, effort or account included. An account a rung spends cannot leave the account list until that rung is gone or moved, as for a Bot's or the reader's account; Claude usage counts it as in use.

6. **设置里怎么排 / How it is ordered in Settings.** 卡片自己问 `claudeCode()`；装好并登录时，「加一个模型」在端点模型后面多一组 Claude 模型（`CLAUDE_MODEL_ALIASES`），加上时是默认思考强度、默认账号。Claude 级名字下面是思考强度的下拉，列了几个账号（或这一级已在某个账号上）时还有账号的下拉，改了就存整份阶梯。手机问不到 Claude Code，就不提供新加，已排上的照样显示、能挪能删能改（2026-10-10 起手机也问得到，和电脑上一样能加，见 [ADR 0061](0061-claude-agent-runner.md) 最后的补记）。/ The card asks `claudeCode()` itself; with Claude Code installed and signed in, "Add a model" lists the Claude models (`CLAUDE_MODEL_ALIASES`) after the endpoint models, added at the default effort on the default account. Under a Claude rung's name is its effort picker and, when several accounts are listed (or the rung is already on one), its account picker; a change saves the whole ladder. The phone cannot ask about Claude Code, so it offers none to add, while the rungs already there show and can be moved, removed and retuned (since 2026-10-10 it can ask and adds them as the computer does; see [ADR 0061](0061-claude-agent-runner.md)'s last addendum).

## 不做的 / Not done

- 不在 Claude 级上按思考强度一档档提：要那样就把同一个模型的几个强度各排一级。/ No stepping a Claude rung through its efforts one by one: order the same model at several efforts as separate rungs instead.
- Claude 级不能填任意模型 id，只有别名；以后要的话照 Bot 面板的自定义模型加。/ Only the aliases can be added, not any model id; a custom id can follow the Bot panel's later if wanted.
