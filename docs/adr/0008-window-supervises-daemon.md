# 窗口监督守护进程，不给守护进程独立登录项

Real Bot 分两个进程是为了窗崩轮次还在，不是为了做无托盘的后台服务。登录项只登记窗口进程；窗口活着（含托盘）才拉起被杀的守护进程。退出（Cmd+Q / 托盘退出 / 关机 / 注销）停两者并中断轮次，不动登录开关。关掉登录启动只影响下次登录。插电只挡空闲睡，合盖照睡。密钥必须守护进程自己能读。

监督线程持有应用状态锁时只读取或更新状态；托盘菜单等需要主线程执行的操作必须在释放锁后调用。Tauri 菜单更新会同步等待主线程，而本机接口查询、Stop 和退出也会读取同一状态锁；锁内更新菜单会使热更新或菜单操作触发双向等待。

健康检查超时不算守护进程已死。`local-api.json` 里的 pid 还在时，窗不拉第二份；第二份进程必须先占端口，抢不到就不打开状态库、不把活轮标成中断。真正退出 / 被杀 / 热重载结束后，pid 没了才拉起，拉起的那一份才恢复中断行。
