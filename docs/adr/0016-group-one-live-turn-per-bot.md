# 群里一人一轮，点名听进已有活轮

部分被 [ADR 0041](0041-control-plane-holds-and-restarts.md)（[ADR 0040](0040-agent-kernel-the-job-owns-state.md) 的 P2）取代（2026-09-30）：「群仍无 Stop」不再成立——引擎级别到了叫停这一级后，群里每个 Bot 正在写的回复都有 Stop，只停那一个 Bot 的这一轮；整个群也能从停止菜单、或一句「停下」叫停。一人一轮、点名听进已有活轮不变。

群里 Bot 互 `@` 时若只分叉，同一人会克隆出多轮，各自盯着过期触发条说话。这不是 hop 熔断能修的：人在一桌只会转头听下一句，不会再长出一个自己。因此该群该 Bot 已有进行中的轮（`running` / `waiting_approval` / `waiting_ask`）时，点名和判断 `join` 改道进那一轮；无活轮才新开。日程仍在你↔私聊分叉。用户一条消息不屠杀全群活轮，群仍无 Stop。应用不代判「达成一致」——只保证一人一轮，并在补全里放一条只含事实的局面（谁有活轮、谁叫醒、用户最近一句）。闭嘴仍是模型读转录后的判断。
