# 选路读得到执行，结论会退出，学习仍由 Bot 落笔

[ADR 0019](0019-agent-routing-and-review.md) 把选模型和复盘都交给了 agent。复盘只在用户追着同一件事说了话之后才跑，选路只读「判成模型的错」的那几条。安静做完的轮次不进选路，工具失败了几次也不进复盘。结果是选路看见的全是「该更强 / 更轻」，方向只会往抱怨那一侧漂；一次写代码选弱了，也会波及后面的寒暄，因为送进去的结论没有当时那条消息。

[ADR 0021](0021-per-bot-memory.md) 让 Bot 自己用 `remember` 写跨会话的事实。能让下一轮更短的那一句，经常出现在链已经结束、教训已经清楚的时候，而那时没有一轮还开着，Bot 也就没有机会落笔。

## 现在

**一轮结束时记下它实际做了什么。** 跳数、工具调用数、工具错误数、完全相同的失败调用次数、写出的文件数，跟终态写在同一行。进程没数到就留空，复盘把空读成不知道，不当成零错误。耗时和花费仍用原来的列。

**复盘看这段执行。** 用户有后续发言时照旧复盘。没有后续发言，但这一轮是端点拒绝、回复不完整，或工具错误不少于两次，也复盘一次。连不上、忙、5xx、流卡住只留在记录里，不为此付一次调用。安静且没有工具错误的完成，仍在本地记成没有不满。

**选路读到对得上的结论，也读到干净做完的例子。** 每条结论带上当时那条消息的摘录和消息类别。摘录和类别都对得上现在这条，才按方向调。同一份载荷里还有这个 Bot 最近干净做完的选择，每个类别至多一条：终态完成、工具没有报错、用户没有追问。没有对得上的失败结论时，保持这个量级。

**一条结论会被请出选路窗口。** 它被照做了两次，两次之后的同类任务都没有更干净（追问没变少，工具错误没变少），就写上退出时间。记录还在，选路不再读它。价格对不上、档位比不出方向，记成不知道，不参与退出。钉死了模型和档位的 Bot 不跑选路，这条结论标成未用于选路。

**链结束之后有一次学习跳。** 只在结论归咎模型，或这一链踩过工具错误并且最终做完时才发。它打在默认端点的默认模型上，工具只有 `remember`、`forget`、`update_skill`。不调用就不写任何东西，也不在主转录留一行。一次事故只写成记忆；已有技能的说明和这件事重合时才改那条技能，不从这一次新造技能。来源消息仍是触发那条，另外记下是哪一条链写下的。

**效果从已有的行里数。** 照做、纠正变少、动手变短都是本机对照，不再开一次模型调用。模型选择记录上能看见这一轮的跳数和工具错误、这条结论后来怎样、这次记下了什么。Bot 的记忆和技能行上能看见：写下之后有几次同类任务，其中几次更短。一次都还没有，就写明还没有后续同类任务。没有被用到不会因此删掉。

## 不做

- 不恢复按权重加减的惩罚表。
- 不在 Bot 背后写记忆。学习跳不调用，就什么都不留。
- 不把经验摊给整个名册，也不按时间给结论折旧。
- 不把工具选择提前到开轮前定死。
