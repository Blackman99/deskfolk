# 花费只透传端点 usage，判断单独记账

2026-09-24 更新：[ADR 0027](0027-spend-ledger-and-view.md) 定义六类调用账本、独立花费视图与可选单价估算；实报与估算分开，token 仍透传端点用量。

2026-09-16 更新：信使移除 token / 花费统计展示，包含顶栏与会话设置统计卡；以下数据记录、缺失值和判断分开记录的决定不变。

花费是展示，不是计费系统：本机乘单价或用分词器估算，都会和供应商账单对不上（缓存 token、推理 token、流被掐断丢末包）。v1 只持久化 Chat Completions `usage` 里能映射的字段；流式一律 `include_usage`；缺了显示「—」而不是 0。OpenAI 的 usage 没有金额，xAI 有 `cost_in_usd_ticks`——只认这一个费用字段，不猜其它 `cost` 的单位，也不做模型价目表。判断不是轮次但确实打了端点，所以走 `spend.judgement_id` 单独一行，不并进 `join` 之后那一轮；否则旁观开销从会话合计里消失，轮次芯片又会把判断钱算到干活的那一轮上。
