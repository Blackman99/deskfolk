# 花费账本、调用类别与独立视图

日期：2026-09-24。对应 [#15](https://github.com/Blackman99/deskfolk/issues/15) 及 #16–#20。更新 [ADR 0006](0006-spend-passthrough-usage.md) 的金额估算与展示决定。

## 决定

1. **花费是持久账本。** 一次端点调用对应一行，行上保存实际端点、模型、思考等级、会话与 Bot 的身份和名称。账本脱离可删除实体的外键；清空历史、删除会话、删除 Bot 都保留花费。对象还在时统计使用当前名称，删除后使用名称快照并标记已删除。旧轮次按模型选择记录回填；历史已经清空或判断未记目标的，模型保留为空。
2. **六类调用分别记录。** `turn` 是轮次补全，`judgement` 是群参与判断，`route_pick` 是选路，`route_review` 是纠正链复盘，`route_learn` 是学习跳，`composer_suggest` 是输入建议。决策路由小计含选路，反馈路由小计含复盘与学习跳；输入建议只归会话、归其他。已经返回 usage 的失败调用照记；有响应但缺 usage 记缺失，连不上且没有响应不记。选路答案无效或复盘结论无效都已经产生调用。安静完成后在本地结束的链没有端点调用。
3. **实报和估算分列。** Token 仅来自端点 usage，缺失保持 null。实报只认 `cost_in_usd_ticks`。模型名单可选 `pricing: { input, output, cached_input? }`，每项单位 USD / 百万 token；输入和输出必需，缓存输入可省略。原 `price` 继续作为选路相对价。探测 `/models` 不填计费单价。配置经设置或 Bot 工具修改，沿用模型名单权限。
4. **信使提供独立花费视图。** 桌面单例窗格标签与窄屏浮层共用内容。按时间、模型、会话、Bot 和调用类别筛选，类别小计、趋势及明细共用同一过滤条件。会话顶栏、会话行、会话设置及模型选择记录保持既有呈现。范围与维度只存本机。

## 估算

满足无实报金额、输入与输出 token 已知、实际端点与模型有计费单价时，在写行时计算：

```text
USD ticks = round(((input_tokens - cached_tokens) × input_rate
                + cached_tokens × cached_input_rate
                + output_tokens × output_rate) × 1e4)
```

1 USD = 1e10 ticks，单价按 1e6 token 计。缓存 token 缺失取 0；缓存单价省略时使用输入单价。推理 token 已包含在 output_tokens，按原口径保留且不重复计价。异常负数、缓存大于输入或超出安全整数范围时保持估算缺失。

估算冻结在 `estimated_cost_usd_ticks`；后续修改、移除单价或删除端点不会改旧行。配置单价前的历史行仍显示未配置单价或用量不足。实报与估算独立求和、独立统计覆盖的调用数，缺金额也统计调用数；全组缺某个指标时仍为 null。

## 查询与同步

`GET /v1/spend/summary` 在守护进程聚合，支持 model / session / bot / kind / day，按客户端传入的 IANA 时区分日。时间范围采用 `[from, to)`。每次响应含整个筛选范围的总计、五类小计和当前分组。`GET /v1/spend` 返回有界分页明细与稳定的时间 / id 游标。已删除实体仍可通过原 id 过滤。

全局快照省去 spend，客户端兼容字段缺失，也不累计 spend.created 行。打开的视图收到事件后去抖重拉。配对设备通过现有加密 RPC 白名单读取同一接口，沿用认证与权限。

## 取舍与边界

名称快照与旧金额占据持续增长的本地存储，换来删除操作后仍可核对历史开销。聚合接口和分页将客户端加载量限制在当前视图所需的数据。只记端点上报的 token；供应商另收费的 MCP 工具不在范围。预算、日限额、告警、自动停机、CSV 导出与跨设备同步视图状态均不在本次范围。
