# 花费

[English](spend.md)

从侧栏或桌面**视图**菜单打开**花费**。桌面为一个窗格标签，手机为全屏浮层。时间可选今天、近 7 天、近 30 天、全部或自定义；总计、调用类别与按日趋势共用筛选。维度表可切换模型、会话、Bot，点列头排序，点行叠加筛选。会话链接和分页调用明细可跳回原会话或触发消息。视图打开时，新调用自动更新数字。

Token 来自端点用量。**实报金额**使用供应商的 `cost_in_usd_ticks`；**估算金额**使用可选的模型计费单价，单位为 USD / 百万 token。在**设置 → 模型服务 → 名单 → 属性**填写输入与输出单价，可另填缓存输入单价；缓存输入留空沿用输入价。改完自动保存，也可一键清空整组。独立的选路参考价继续用于挑模型。估算写入每条新调用后保持不变，后续改价保留历史；缺用量或未配单价时保留缺失值提示。

账本记录轮次补全、判断、选路、复盘、学习跳和输入建议（只在按发送按钮旁的 ✨ 时起草）。删会话、删 Bot 或清空历史都保留花费和名称快照。会话顶栏、列表行和设置沿用现有展示。花费功能不设预算或自动停机，MCP 工具另外收取的费用也无法统计。
