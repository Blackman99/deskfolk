# 花费

[English](spend.md)

从桌面**工具**（第二项）、手机搜索旁的工具菜单，或桌面**视图**菜单打开**花费**。再打开一次会定位到已经在显示它的标签。桌面为一个窗格标签，手机为全屏浮层。内容滚动时，窗格顶栏保留时间范围、刷新、当前筛选和**概览 / 调用明细**切换。时间可选今天、近 7 天、近 30 天、全部或自定义；切换视图保留筛选和已经载入的调用。

**概览**先显示总 Token 和调用次数，旁边分别展示实报、估算金额；输入、缓存、输出和推理分项及可展开的用量说明提供细节。按日趋势与调用类别共用筛选；点柱形或用键盘聚焦可看对应日期和值，方向键逐条移动。长范围合成最多 28 个带日期区间标注的柱形，实报与估算图使用共同刻度、分别显示。

用量分布可切换模型、会话、Bot，点列头排序，点名称叠加筛选。内容区窄于 620px 时，表格转为纵向列表，提供排序选择和可展开的 Token 分项；桌面分屏、浮动小窗和手机都按实际内容宽度切换，长名称在行内换行。**调用明细**采用同样的紧凑布局，本地化日期，可展开用量分项，点**查看触发消息**跳回原会话；更多调用分页载入。调整窗格大小保留当前视图和数据；新调用自动更新数字。

Token 来自端点用量。**实报金额**使用供应商的 `cost_in_usd_ticks`；**估算金额**使用可选的模型计费单价，单位为 USD / 百万 token。在**设置 → 模型服务 → 名单 → 属性**填写输入与输出单价，可另填缓存输入单价；缓存输入留空沿用输入价。改完自动保存，也可一键清空整组。独立的选路参考价继续用于挑模型。估算写入每条新调用后保持不变，后续改价保留历史；缺用量或未配单价时保留缺失值提示。

账本记录轮次补全、判断、选路、复盘、学习跳、输入建议（只在按发送按钮旁的 ✨ 时起草）和整理跳（你每发一条消息、每个规划静下来后各一次，归决策路由，不归任何 Bot）。删会话、删 Bot 或清空历史都保留花费和名称快照。会话顶栏、列表行和设置沿用现有展示。花费功能不设预算或自动停机，MCP 工具另外收取的费用也无法统计。
