# Code of conduct / 行为准则

本准则适用于项目的 Issues、Pull Requests、代码审查及其他由维护者管理的项目交流空间。

## 参与方式

- 尊重不同经验、背景与观点，欢迎中文和英文交流。
- 围绕事实、复现步骤和方案讨论，评价工作而非攻击个人。
- 给出可行动的反馈，接受更正，尊重参与者的时间与边界。
- 公开日志、截图或对话前取得必要授权并移除个人信息。

骚扰、歧视性言论、人身攻击、威胁、泄露他人私人信息以及持续干扰讨论不被接受。

## 处理与报告

维护者可以要求修改内容、移除违规内容、锁定讨论，或限制反复 / 严重违规者的参与。处理应与行为及影响相称，并尽可能说明原因，同时保护报告者隐私。

可使用托管平台的私密举报功能。若需要联系维护者而没有已公布的私密渠道，请只提交不含敏感细节的联系请求，待获得私密渠道后再提供事实。安全漏洞另按 [SECURITY.md](SECURITY.md) 报告。

## English

This policy applies to project Issues, pull requests, reviews, and other project spaces managed by maintainers. Treat participants respectfully, discuss evidence and ideas rather than attacking people, provide actionable feedback, accept corrections, and protect private information. Chinese and English participation is welcome.

Harassment, discrimination, personal attacks, threats, disclosure of private information, and persistent disruption are unacceptable. Maintainers may request edits, remove content, lock discussions, or restrict participation proportionately while protecting reporters' privacy.

Use the hosting platform's private reporting tools. If no private maintainer channel is available, request one without publishing sensitive details. Report security vulnerabilities according to [SECURITY.md](SECURITY.md).
